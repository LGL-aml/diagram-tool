Dùng cho type: architecture. Bấm một dòng để chèn vào spec.

Các trường spec

architecture — clusters, nodes (icon), edges. Renderer: diagrams + Graphviz.

context / flow / dependency — nodes (kind hoặc shape), edges. Renderer: Graphviz.

sequence — actors, messages. style: return là mũi tên phản hồi.

stack — layers từ trên xuống dưới.

roadmap — YYYY-MM hoặc YYYY-Qn, status done / active / planned / risk.

schematic — library: electrical | dsp | flow | logic, mỗi phần tử là class Schemdraw.

Cạnh dùng from, to, label, style, tone. Cùng footer thì cả bộ hình trong báo cáo khớp nhau.
